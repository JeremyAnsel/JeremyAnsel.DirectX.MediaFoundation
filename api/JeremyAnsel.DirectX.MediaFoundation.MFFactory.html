    MFFactory()

    Initializes the platform object. Must be called before using Media Foundation. A matching MFShutdown call must be made when the application is done using Media Foundation. The "Version" parameter should be set to MF_API_VERSION. Application should not call MFStartup / MFShutdown from workqueue threads.
