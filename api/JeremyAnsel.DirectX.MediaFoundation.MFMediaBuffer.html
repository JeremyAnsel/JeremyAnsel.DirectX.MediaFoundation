    Class MFMediaBuffer

    The IMFMediaBuffer interface represent a buffer of multimedia data for any possible multimedia type. It provides methods for accessing the buffer pointer, the current length, and the maximum length of the buffer

    Unlock()

    The Unlock method signals completion of the use of the buffer pointer acquired via the Lock method.

    Declaration
    public void Unlock()
    Remarks

    The buffer pointer acquired via Lock can no longer be used once the caller signals completion of that usage via the Unlock call. Also, note that Unlock must be called the same number of times that Lock has been called in order to signal completion of the use of the buffer pointer.
