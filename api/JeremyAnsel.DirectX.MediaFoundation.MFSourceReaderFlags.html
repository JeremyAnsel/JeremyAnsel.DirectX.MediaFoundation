    Enum MFSourceReaderFlags

    The enumeration type defines the various flags that can be returned from the MF Source Reader when retrieving the next sample.

    Namespace: JeremyAnsel.DirectX.MediaFoundation
    Assembly: JeremyAnsel.DirectX.MediaFoundation.dll
    Syntax
    [Flags]
public enum MFSourceReaderFlags

    Fields

    Name Description
    AllEffectsRemoved

    Indicates that all transforms inserted by the application have been removed for a particular stream. This could be due to a dynamic format change from a source or decoder that prevents custom transforms from being used because they cannot handle the new media type.
    CurrentMediaTypeChanged

    Specifies that the current media type for the stream has changed.
    EndOfStream

    Specifies that the stream has ended.
    Error

    Specifies that an error has occurred while processing sample requests. If this is set, then no other calls should be made on the source reader besides shutting it down.
    NativeMediaTypeChanged

    Specifies that the native media type for the stream has changed.
    NewStream

    Specifies that one or more new streams have been created. The application can modify stream selection and configure output media types for the new streams.
    None
    StreamTick

    Specifies that there is a gap in the stream.
