    MF_READWRITE_D3D_OPTIONAL Data type: UINT32 This attribute is used to tell Source Reader\Sink Writer that application can accept non-DX samples. Source Reader will attempt to provide DX samples but will fallback to sysmem allocation if DX allocation fails. This attribute is only valid when D3D manager is set.
